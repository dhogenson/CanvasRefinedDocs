---
title: Install
description: Install Canvas Refined in Chrome or Firefox and connect it to your school's Canvas website.
---

Install Canvas Refined from your browser's extension store. You need access to your school's Canvas website and a browser that allows extensions.

## Chrome

1. Open [Canvas Refined on the Chrome Web Store](https://chromewebstore.google.com/detail/canvas-refined-dark-mode/ihienfbdfdamhmhhiokjnjmpjgbenedg).
2. Select **Add to Chrome**.
3. Review the requested permissions and confirm the installation.

## Firefox

1. Open [Canvas Refined on Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/canvas-refined/).
2. Select **Add to Firefox**.
3. Review the requested permissions and confirm the installation.

## Supported browsers

Chrome and Firefox have dedicated store listings. Other Chromium-based browsers, such as Edge or Brave, may be able to install the Chrome version, but browser-specific behavior can differ.

Do not assume that mobile browsers, the Canvas mobile app, or school-managed browsers support the extension. If installation is blocked by your organization, ask your school's IT team rather than trying to bypass the restriction.

## After installation

1. Open your school's Canvas website and sign in normally.
2. If Canvas was already open, refresh the page.
3. Open your browser's extensions menu and select **Canvas Refined**. Pin it to the toolbar if you want easier access.

You should see dark mode and dashboard enhancements on a recognized Canvas site. An installation welcome page may also open; you do not need to keep it open.

## Add your school's Canvas site

If the extension does not recognize your school:

1. Open the Canvas Refined popup.
2. Select **+ Add canvas**.
3. Enter your school's Canvas website address, such as `https://canvas.example.edu`, not a link to an individual assignment.
4. Make sure your browser allows the extension to run on that site, then refresh Canvas.

Only add sites you know are your school's Canvas instance. See [Privacy and Permissions](/CanvasRefinedDocs/privacy/) for why the extension requests website access.

## Not seeing any changes?

Check that Canvas Refined is enabled in your browser's extension manager, confirm site access, and refresh Canvas. If that does not help, follow [Nothing changes on Canvas](/CanvasRefinedDocs/help/troubleshooting/#nothing-changes-on-canvas).
