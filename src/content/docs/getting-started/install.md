title: Install
description: Install Canvas Refined in Chrome, Firefox, and compatible browsers.
---

Install Canvas Refined from your browser’s extension store.

## Chrome and Chromium-based browsers

1. Open [Canvas Refined on the Chrome Web Store](https://chromewebstore.google.com/detail/canvas-refined-dark-mode/ihienfbdfdamhmhhiokjnjmpjgbenedg).
2. Click **Add to Chrome**, on that page
3. Confirm the installation and review the requested permissions.

## Firefox

Kind of the same thing for Chrome
1. Open [Canvas Refined on Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/canvas-refined/).
2. Click **Add to Firefox**.
3. Review the requested permissions and confirm the installation.

## After installation
After you install Canvas Refined, you will be brought to a landing page from Canvas Refined.

To see the changes:
1. Open your school’s Canvas website.
2. If Canvas was already open, refresh the page.

If you don't see anything go to [Quick Start](/getting-started/quick-start) for more instructions.

## Supported browsers

Canvas Refined is available for Chrome and Firefox. Other browsers built from chromium or firefox may also support the extension

## Not seeing any changes?

- Refresh your Canvas page after installing.
- Make sure Canvas Refined is enabled.
- Check whether your browser has allowed the extension to access your Canvas website.

If all else fails try and get help in the [discord server](https://discord.gg/GjFh4JA3wh)
