---
title: Quiz Safe Mode
description: Reduce Canvas Refined's changes on quiz pages without treating it as an exam approval guarantee.
---

Quiz Safe Mode turns off most Canvas Refined features on recognized quiz pages. It is **off by default**.

## Enable it

1. Open the Canvas Refined popup.
2. Find **Quiz Safe Mode** using **Search features...** if needed.
3. Turn it on before opening a quiz.
4. Check the quiz page before starting the attempt. If the page is already open, refresh only when it is safe to do so.

Turn the setting off again to restore the extension's normal behavior on quiz pages. Other Canvas pages continue to use your regular settings.

:::caution[Follow your instructor's exam requirements]
Quiz Safe Mode is not approval to use the extension during an exam. It does not disable other extensions, bypass restrictions, or guarantee compatibility with a proctoring tool.
:::

## Limitations

Quiz detection depends on the page. External quiz tools, embedded tools, and different quiz implementations may behave differently.

If your school requires extensions to be disabled, [disable Canvas Refined in your browser](/CanvasRefinedDocs/help/troubleshooting/#temporarily-disable-canvas-refined) rather than relying on Quiz Safe Mode.

If something goes wrong during an active attempt, follow your instructor's instructions and contact course support. Avoid troubleshooting changes or refreshing a timed quiz unless you know doing so is safe.
