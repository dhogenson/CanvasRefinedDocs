---
title: Quiz Safe Mode
description: Use a more default Canvas experience on quiz pages.
---

Quiz Safe Mode turns off most Canvas Refined features on quiz pages. It's off by default.

## Use it

Enable **Quiz Safe Mode** in the extension popup if you prefer a more default Canvas quiz experience. Turn it off there to use the extension's normal behavior again.

This only affects Canvas Refined. It doesn't disable other extensions or guarantee compatibility with exam or proctoring tools.
