---
title: Dashboard Notes
description: Write personal dashboard notes with Markdown and understand how they are saved.
---

Dashboard Notes adds a personal writing area to your dashboard. It supports Markdown and is **off by default**.

## Write your first note

1. Open the extension popup and select **Widgets**.
2. Enable **Dashboard Notes**. In older versions, find the toggle in the main popup.
3. Open your Canvas dashboard and click the notes area to edit it.
4. Type a note, then click outside the editor to see the formatted version. Current versions also support **Escape** or **Ctrl+Enter** / **Cmd+Enter** to leave editing.

Notes save automatically shortly after you stop typing; there is no separate Save button. Allow a moment before closing the page.

## Try Markdown

```markdown
## This week

- Read chapter 3
- Ask about the lab report

**Remember:** bring a calculator.

- [ ] Review practice questions
- [x] Download the study guide
```

Use Markdown for headings, bold text, lists, and checklists. Current versions also provide formatting buttons and **Ctrl+B** / **Cmd+B** for bold and **Ctrl+I** / **Cmd+I** for italics.

## Move or hide the notes

Under **Widgets → Dashboard Notes**, choose the position and height. Turn the feature off to hide the area; disabling it does not itself delete the saved text.

## Where notes are saved

Notes use the browser's extension sync storage. Depending on your browser and sync settings, they may sync within your browser profile; do not assume they transfer between Chrome and Firefox or between unrelated profiles.

The saved text is not an assignment submission or a per-course Canvas note. The extension uses one notes setting rather than a separate notebook for each school.

:::caution[Keep a separate copy of important notes]
Sync storage has size limits and is not a backup service. Copy important text elsewhere before resetting settings, changing profiles, or uninstalling. Theme exports do not include your note text.
:::

For more about storage, see [Privacy and Permissions](/CanvasRefinedDocs/privacy/). If notes disappear, confirm that you are using the same browser profile and that the feature is still enabled before resetting anything.
