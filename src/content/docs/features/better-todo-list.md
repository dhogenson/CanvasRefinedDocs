The Better Todo List organizes coursework on your Canvas dashboard. It is **enabled by default**.

## Use it

1. Open your Canvas dashboard and find the to-do list.
2. Open the extension popup and find **Better Todo List**.
3. Set the time frame and item limit, then return to Canvas to check the result.

*Filter diagram, not a screenshot. An item outside your selected view may still exist in Canvas.*

## Choose what appears

| Setting | Use it to |
| --- | --- |
| **Time frame** | Choose the date range you want to review. |
| **Max items to show** | Control the list's length. |
| Assignment scores | Show available scores alongside work. |
| Recent feedback options | Reduce or hide feedback entries. |

Try a wider time frame and a larger item limit if expected work is missing. Other dashboard or course filters can also affect the available items.

## Adjust the presentation

Options include hover previews, 24-hour time, list scrolling, and completion celebrations. Turn off celebrations if you prefer less motion.

Hover previews are a convenience; open the actual assignment to read all instructions and submission requirements.

## Completion is not submission

Marking something complete in a to-do list is not the same as submitting an assignment. Some to-do actions update Canvas planner completion state. Custom tasks created through the list are Canvas planner notes, not [Dashboard Notes](/CanvasRefinedDocs/features/dashboard-notes/).

Always use the assignment's own page to submit work and check submission status.

## Limitations and common problems

The list is a filtered view, not a guarantee that every task, announcement, or deadline appears. Canvas permissions, course content, dates, and list settings all matter.

Turn **Better Todo List** off in the popup if you prefer Canvas's normal dashboard list. For missing work, see [troubleshooting](/CanvasRefinedDocs/help/troubleshooting/#an-assignment-or-grade-is-missing).
