title: Dark Mode
description: Choose dark mode colors and control when they apply.
---

Dark mode changes Canvas's colors for a darker appearance. It's enabled by default.

## Use it

Open the extension popup and select **Edit Dark Mode** to choose a preset or adjust individual colors. Turn off **Dark mode** in the main popup to return to Canvas's normal appearance.

## Settings

Enable **Automatic dark mode** to set a start and end time, or select **Use device dark mode settings** to follow your device instead.

For fonts and custom backgrounds, open **Styles** in the popup. Choose a background preset or paste an image URL.

Dark mode may not cover every embedded tool or piece of course content.
