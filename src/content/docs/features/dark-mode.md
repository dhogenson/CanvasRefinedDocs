title: Dark Mode

Dark mode changes Canvas's interface colors for a darker appearance. It is **enabled by default**.

## Choose a preset

1. Open the Canvas Refined popup.
2. Select **Edit Dark Mode** (or **Dark Mode**).
3. Choose a preset, or adjust individual background, text, link, and sidebar colors.
4. Return to Canvas to check readability, including links and assignment feedback.

*Illustration, not a screenshot. Dark mode changes presentation, not course content.*

## Control when it applies

| Mode | What to set |
| --- | --- |
| Manual | Turn off **Automatic dark mode** and uncheck **Use device dark mode settings**. Use the main **Dark mode** toggle. |
| Scheduled | Enable **Automatic dark mode**, set start and end times, and leave the device option unchecked. Times use your device's clock. |
| Follow your device | Select **Use device dark mode settings** under the automatic options. The main dark-mode styling follows your device's light/dark preference. |

Use one approach at a time. The device preference controls the main dark-mode color styling when selected; a schedule is not a second time window that must also match.

## Fonts and backgrounds

Open **Styles** to choose fonts or a background preset, or supply an image URL. These are separate from the dark-mode color preset. See [Customization](/customization/) and [external resources](/privacy/#external-resources).

## Restore the appearance

- To undo custom colors, choose the **Default** dark-mode preset.
- To return to Canvas's normal colors, disable automatic and device-controlled dark mode, then turn off **Dark mode**.
- Other customizations, such as card styles or background images, have their own settings.

## Limitations and common problems

Embedded tools, documents, images, videos, and instructor-formatted content may keep their own colors. Dark mode cannot guarantee that every third-party page will match.

If text becomes hard to read, try a built-in preset before changing more colors. If a page still looks wrong, see [A page looks broken](/help/troubleshooting/#a-page-looks-broken).
