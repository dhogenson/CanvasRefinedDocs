---
title: Global Canvas Search
description: Search modules and assignments across your Canvas courses.
---

Global Canvas Search helps you find modules and assignments without opening each course separately. It's off by default.

## Use it

Enable **Global Canvas Search** in the extension popup. While on Canvas, press **Ctrl+K** (or **Cmd+K** on Mac) and type your search.

This searches modules and assignments, not every type of Canvas content. Turn it off in the popup if you don't want to use the shortcut.
