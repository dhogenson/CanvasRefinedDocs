---
title: Global Canvas Search
description: Find modules and assignments across courses using Ctrl+K or Cmd+K.
---

Global Canvas Search helps you find modules and assignments without opening each course separately. It is **off by default**.

## Open search

1. Enable **Global Canvas Search** in the extension popup.
2. Return to your Canvas website.
3. Press **Ctrl+K** on Windows or Linux, or **Cmd+K** on macOS.
4. Type a module or assignment name and open a result.

This is different from **Search features...** in the extension popup, which finds settings, and the search on this documentation site.

## Narrow your search

In current versions, try:

| Query | Purpose |
| --- | --- |
| `chapter 5` | Find matching indexed items across courses. |
| `@chemistry chapter 5` | Narrow results to a matching course. |
| `@grades` | Find course grade-page shortcuts. |
| `@home` | Jump to the dashboard. |

Press **Escape** to close search. Turn the feature off in the popup if you do not want its keyboard shortcut.

## If results are missing

Search builds an index from Canvas, so the first search may take time and show partial results.

1. Wait for indexing to finish.
2. Try a shorter or different part of the item's name.
3. Select **Refresh** in the search window to rebuild the index.
4. Open the course directly and check whether Canvas makes the item available to you.

## Limitations and saved data

Search primarily indexes modules, their items, and assignments from active courses available to your account. It is not a full-text search of every file, discussion, message, or page body. Large course collections, request limits, and Canvas permissions can leave the index incomplete.

The index is cached in local extension storage for faster searches. See [Privacy and Permissions](/privacy/).
