## Choose a support channel

- **Ask a question:** Join the [Canvas Refined Discord server](https://discord.gg/GjFh4JA3wh) for community help.
- **Report a reproducible bug:** Search [GitHub issues](https://github.com/GuySandler/CanvasRefined/issues) for an existing report, then [open an issue](https://github.com/GuySandler/CanvasRefined/issues/new) if needed.
- **Suggest a feature:** Explain the task you want to accomplish and why the current options do not cover it. Use GitHub issues or the appropriate Discord channel.
- **Check recent changes:** See [GitHub releases](https://github.com/GuySandler/CanvasRefined/releases). Store versions may arrive at different times.

For missing submissions, course access, grading decisions, or exam rules, contact your instructor or school's Canvas support instead.

## Before reporting a bug

1. Follow the relevant [troubleshooting checks](/help/troubleshooting/).
2. Find your extension version in your browser's extension manager.
3. Check whether the problem happens with Canvas Refined disabled.
4. If safe, check whether another Canvas extension causes a conflict.
5. Write down the shortest steps that reproduce it.

## Bug report template

Copy this into your report:

```text
Summary:
Browser and version:
Operating system:
Canvas Refined version:
Affected page type (dashboard, assignments, grades, etc.):

Steps to reproduce:
1.
2.
3.

Expected result:
Actual result:

Does it happen with Canvas Refined disabled?
Other Canvas-related extensions:
Settings or presets relevant to the issue:
Troubleshooting already tried:
```

If the problem began after an update, include the previous working version if you know it. Do not downgrade to an untrusted extension package to test.

## Share screenshots safely

Crop to the affected controls and remove names, email addresses, student IDs, course identifiers, grades, submissions, and private feedback. Check browser tabs, address bars, and tooltips too.

Never share passwords, cookies, session links, or Canvas API tokens. Logs and settings exports can contain URLs or course details; inspect them before attaching them publicly.

For a sensitive privacy concern, use the contact information in the [upstream privacy policy](https://github.com/GuySandler/CanvasRefined/blob/main/PRIVACY_POLICY.md) rather than posting the details in a public issue.
