
 ### 1. Getting Started

 - Overview — what Canvas Refined does, who it’s for, and a few screenshots.
 - Installation — how to install it, supported browsers, and any compatibility requirements.
 - Quick start — the first things to do after installing.
/
 ### 2. Features

 Give each major feature a page explaining:
 - What it does.
 - How to enable or use it.
 - Available settings.
 - Any limitations.

 Organize these around your actual features rather than documenting every toggle separately.

 ### 3. Customization

 Explain how users can adjust the appearance and behavior, restore defaults, and manage preferences.

 ### 4. Troubleshooting & FAQ

 Cover common questions like:
 - Why aren’t my changes showing up?
 - Does it work with my school’s Canvas?
 - Could another extension be causing a conflict?
 - How do I temporarily disable it?

 Only include questions relevant to what the extension actually supports.

 ### 5. Support & Feedback

 Where to report bugs or request features, plus what to include in a report: browser, extension
 version, reproduction steps, and screenshots with personal information removed.

 ### 6. Privacy & Permissions

 Explain what permissions it needs, why it needs them, and whether any Canvas data is stored or
 transmitted. Link to your privacy policy if it’s separate.

 Optional later: a changelog and contributor/developer documentation.

 For launch, I’d prioritize Overview → Installation → Features → Troubleshooting → Privacy, keeping
 the rest lightweight. Your homepage should quickly answer “What does this improve?” and provide an
 obvious Install button and Get started link.
